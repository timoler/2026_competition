# 模型评价（论文可直接改写）

> 按「有效性 → 稳定性 → 适用范围 → 局限性 → 可推广性」组织，供论文手改写为正文，
> 不用「模型完美 / 绝对准确 / 完全鲁棒 / 严格证明所有情景」等过度表述。

## 1. 模型有效性

- **Q1**：单点运输方案在返航安全余量 20% 设定下为 18 架次，达到按各服务区
  质量/体积/安全载荷推得的架次数理论下界，并经 7 项独立约束验证（PASS）。
- **Q2**：将多点运输、资源（无人机/共享电池）、时限、能源 SOC 一体化建模，得到满足
  全部 12 项约束的可行调度（26 架次、完工时间 6973.6 s、最低 SOC 20.95%）。
- **Q3**：把地形视线（LOS）遮挡、中继无人机部署、运输调度与逐秒通信验证结合，通过
  联合调度把未覆盖样本从 407 降为 0，57 项严格验证 PASS（strict_feasible=True）。
- **Q4**：以「同一运输架次访问的服务区不可拆」为原子块，对分区方案做确定性全枚举
  （2 组 2047、3 组 86526），并配 27 项独立验证（PASS）。
- **四问递进**：构成「运输规划（Q1）→ 动态调度（Q2）→ 通信保障（Q3）→ 分区资源
  配置（Q4）」的完整链条。

## 2. 模型稳定性 / 敏感性

- **Q1**：安全余量 10%–20% 架次数稳定为 18，25%/30% 才增至 19/20 —— 载荷与余量设定内
  结论稳定。
- **Q2**：最低返航 SOC 对能耗参数较敏感 —— 能耗统一上浮约 2% 即跌破 20% 下限，能源安全
  裕量较小。
- **Q3**：通信覆盖在时间步长（1.0/0.5/0.25 s）与 LOS 采样间距（15/10/5 m）的网格细化下
  均保持 0 未覆盖；但 R02 物理周转余量约 0.45 s，时序裕量薄。
- **Q4**：字典序目标把「库存缺口最小」放在首位，最优结构对目标优先级敏感（倾向孤立
  单点、组间不均衡）。

## 3. 模型适用范围

- 适用于题目给定的地形、服务区分布、机型/电池/中继参数与确定性时间模型。
- Q1/Q2 的能耗数值在「水平能耗 = 可用能量×距离/等效航程、爬升能耗 = 势能/效率」的
  **本文建模假设**下成立，不视为题目唯一确定。
- Q3 的「0 未覆盖」是在给定时间步长、LOS 采样间距与服务窗口约定的**采样口径**下成立，
  不等价于连续时间、连续空间的严格证明。
- Q4 的资源核算在「分区独立执行、资源不跨组调配」口径下成立；中继共享按放宽口径
  （可跨组重复配置）处理，另有严格绑定敏感性对照。

## 4. 模型局限性（须在正文诚实写出）

1. Q1/Q2 显式能耗公式（水平、爬升）属本文**补充假设**，直接影响最大载荷、架次、能耗与 SOC。
2. Q2 最低返航 SOC 安全裕量较小（20.95%，能耗上浮约 2% 即不可行）。
3. Q2 为启发式求得的较优可行解，**不证明全局最优**。
4. Q3 通信验证是**离散采样证据**，不是连续时间严格证明。
5. Q3 R02 物理周转余量约 0.45 s，时序裕量小，未覆盖返航/周转/延误扰动。
6. Q4 的 `workload_imbalance` 仅为字典序**末位辅助指标**，不计算 CV，不声明均衡最优。

## 5. 可推广性

- 建模框架（组批 + 多点调度 + LOS 中继联合 + 原子块分区枚举）可迁移到同类
  无人机救援/物流问题，但能耗、地形遮挡、时序裕量等参数需按实际场景重新标定。
- 后续若需更强结论，可沿「区间/自适应 LOS 验证」「周转时间扰动实验」「固定基准归一化
  均衡指标」方向扩展（本轮未做）。
