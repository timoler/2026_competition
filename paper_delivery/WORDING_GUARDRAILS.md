# 论文措辞红线（禁用 / 推荐）

> 论文手在表述结果时必须遵守。左边为**禁止**的过度表述，右边为**推荐**的诚实表述。

## Q1

| 禁用 | 推荐 |
|---|---|
| Q1 得到唯一最优解 | 在本文能耗及安全余量假设下，方案达到架次数理论下界 |
| 能耗公式由题目唯一确定 | 水平/爬升能耗采用本文补充建模假设（见能量假设审计） |
| 方案在任意条件下最优 | 结论限于本文载荷、安全余量与组批模型假设 |

## Q2

| 禁用 | 推荐 |
|---|---|
| Q2 获得全局最优调度 | 通过多起点构造与局部改进获得满足全部约束的较优调度方案 |
| Q2 具有良好鲁棒性 | 标称能耗参数下满足约束，但最低 SOC 对能耗扰动较敏感（上浮约 2% 即跌破 20%） |
| 26 架次为最少架次 | 26 架次为当前搜索策略下的可行结果，未证明架次数最优 |
| 能耗公式为官方唯一口径 | Q2 与 Q1 采用同一建模思想的水平/爬升能耗假设 |

## Q3

| 禁用 | 推荐 |
|---|---|
| 严格证明全过程连续 100% 通信 | 在给定时间步长、LOS 采样间距与服务窗口约定下，未检测到未覆盖通信样本 |
| 数学证明不存在任何瞬时中断 | 结论为离散采样口径，不构成连续时间/连续空间严格证明 |
| Q3 调度具有充分时间裕量 | 当前确定性设定下满足物理周转约束，但 R02 最小周转余量约 0.45 s |
| 方案覆盖任意地形 | 结论限于题目给定 DEM 与确定性时间模型 |

## Q4

| 禁用 | 推荐 |
|---|---|
| Q4 实现工作量均衡最优 | 工作量差异指标作为资源缺口/规模目标之后的末位辅助择优依据 |
| 各组高度均衡 / CV 最小 | 本模型不计算 CV，不声明组间工作量均衡最优 |
| 3 组方案为全枚举唯一最优（若指「均衡」） | 全枚举在字典序目标（缺口→规模→均衡）下确定最优；均衡为末位 tie-break |

## 通用

| 禁用 | 推荐 |
|---|---|
| 模型完美 / 绝对准确 / 完全鲁棒 | 模型在题面约束与本文补充假设下验证通过 |
| 严格证明所有实际情景均可行 | 已验证情景与口径下可行，边界见各问局限性 |
| 把条件 PASS 写成无条件最优 | 保留「在……假设/口径下」的限定语 |
