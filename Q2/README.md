## 时间与能耗口径

- t=0 为任务开始，机体在 O01，电池全满。准备时长为固定准备 + 每箱装载 × 箱数。
- 到达服务点即交接，时长为该机型基础交接 + 每箱增加交接 × 本站箱数。同站本批箱统一在交接完成时视为送达。
- 附件未给运输机单独周转时间，本场景设额外周转 0 秒。下一次准备已包含下次装载；可通过配置改变并重算。
- 飞行时间为爬升高度/爬升速度 + 水平距离/巡航速度 + 下降高度/下降速度；去返程分别计算。
- 题面等效航程：`L(q)=L0-(L0-LF)*(q/Q)^1.5`。q 为进入航段时未交付货物质量，最后空载返程 q=0。
- **补充假设**水平能耗 `Euse*d/L(q)`；**补充假设**爬升能耗 `(含电池空载质量+q)*9.80665*h_up/(eta*3.6e6)`。核对 DOCX 正文与 Office Math 后，未找到这两项具体函数，不能当成题面原公式。队友共同确认后才可作为 Q1/Q2/Q3 统一口径。
- 按题面分解，下降附加能耗为零，不另加准备/交接悬停能耗；这是题目简化，不是实际飞机下降不耗电。含电池空载质量不重复增加电池重量。
- 全架次能耗包含返程；`SOC=1-Etrip/Euse`，附件 20% 返航下限映射为 rho=.2，`Etrip <= (1-rho)*Euse`，余量只扣一次。
- 机体占用 `[准备开始, 返回+额外周转)`。电池保守从准备开始占用，返回即开始充电，充满再用。同型电池可跨机体共享，不跨机型。
- 充电时间：SOC s<.9 时为 `Tfull*(.65*(.9-s)/.9+.35)`，否则为 `Tfull*.35*(1-s)/.1`。不同电池并行充电；不增加附件未给的有限充电/装载工位数。
- 累计作业时间为各架次准备、装载、飞行、交接、周转之和，不含等待；全部任务完成时间为最后返抵 O01 时刻，不计最后充电。
- 原件未给电池单体编号，由库存派生 `BAT-A-01` 等；不是附件现成序列号。

## 地理计算

水平投影 EPSG:32649，原始 DEM 为 EPSG:4326，不重采样。MAT 仿射参数定义像元半格边界。对 UTM 直线逆投影，使用本地区域六阶 Krueger 逆投影的全区间导数符号检查单调性，再求所有原生经纬格线交点。取交点及每个已分割区间内对应的像元，边/角接触包含全部邻格；不是任意步长采样最高高程。

根容差为路线比例 `1e-13`，格线接触容差 `1e-7` 像元，极近邻可保守纳入。区间符号不能确定、路径超界或有缺失 DEM 均报错。该数值区间检查限于本地 WGS84/UTM49N，六阶级数存在截断限制，不是任意地区/投影的形式化证明。

节点采用附件指定海拔，中心作业海拔为地面，服务区为地面 +30 m；巡航海拔为最高 DEM +50 m。每站下降至作业海拔后再起飞，负高度直接报错。Q3 新增节点或航线须重新计算几何，不能套用旧航段表。

1. 其他货箱 `sum(应急优先系数*max(交付完成-期望,0))`；
2. 最后返抵时刻；
3. 全部能耗；
4. 架次数。

## 核验与限制

- `validate.py` 不调用核心 trip/leg，从 CSV 与参数另行累计载荷、时序、能源和资源；检查箱覆盖、质量、体积、硬时限、机体/电池冲突、充电、返航 SOC 和全部汇总。结果见 `q2_validation.json`。不得用 Python -O。
- `test_transport.py` 检查充电边界、安全载荷、两站递减载荷、所有轨迹边界、重算及错误注入；见 `q2_tests.txt`。
- 第二 AI 初审促成修复：安全余量 override 未传入单点接口、配置语义标签未校验、汇总校验遗漏、DEM 采样单调判据不足。更新后复核以 `q2_independent_review.md` 为准，不能把初审旧快照指标当作当前结果。
- 唯一物理实现为 `transport_core.py`。Q1/Q3 可以导入，或由协调人迁移至 shared，不能复制为各自修改的公式。共享补充假设尚待队友确认。
- 最低 SOC 仅比 20% 高约 0.95 个百分点，能耗口径改变可能使方案不可行，必须重新运行。
- 未考虑通信、中继、气象、避碰或空域约束；最多四站是优化搜索限制。不是实飞操作计划。
