# 两架中继 100% 连续通信可行性实验报告

**实验目的**：严格验证在原题资源限制（仅 R01/R02 两架中继）下，能否通过「中继动态调度 + 运输架次错峰」实现 Q3 的 100% 连续通信。**不放松任何原题约束**。

**正式口径**：1 s 时间网格；10 m LOS；接入链路 + 回传链路同时有效；AGL ≤ 300 m；仅 R01/R02；中继能源组件 ≤ 6、每组件 3.2 kWh、可用 ≤ 2.56 kWh、返航 SOC ≥ 20%；Q2 运输硬约束全部保持；`uncovered_samples == 0` 才 PASS。

## 基线确认

- Q2 共 26 个运输架次，总通信验证样本 **36351**。
- 原题两架中继 R01/R02，当前最佳已找到 **uncovered_samples = 407**，coverage ≈ 98.880361%，FAIL。
- 三架增配 R03：uncovered_samples = 0，100%（**仅作增配对照，不得用于证明原题已解决**）。

## 407 个失败样本的根因

`analyze_two_relay_failures.py` 重新得到全部 407 个失败样本，结论：

- **全部 407 个样本集中在单一架次 T011（U07/C 型）的一段连续 407 秒**，区间 [4175.4, 4582.4]。
- 位置固定为 S004 服务点上空 (319529, 2553224.7)，海拔仅 228–242 m（**下降进近 + 返航爬升的低空段**）。
- 失败原因统一为 `direct_fail + R01_access_fail + R02_access_fail`：**纯空间遮挡**——两个中继都在服务、都有回传，但都看不见这个低空谷地。
- 同时盲区运输机数 = 1（非多机并发问题）。

**结论**：407 失败 = **一个空间盲区（S004 低空谷地）**，属于"西向第三视锥"。R01（北）与 R02（南）都无法看见 S004 低空点，需要第三个视锥（R03 所在的西侧位置）才能覆盖。这是**三视锥问题**，不是时间冲突、能量或位置冲突。

## 各阶段结果

### E0 —— 严格复现基线
重新加载当前两架最佳方案，`validate` 复现 **407 / 98.880361%**。✅ 与正式基线一致。

### E1 —— 连续位置/高度静态搜索（两架各一次固定悬停）
- 原正式搜索已对 300 m 格点候选（1429 个）做**穷举两点组合**，最小中断 **409**；再经 x/y/AGL 局部细化（150/50/15/5 m、AGL 250/275/300）得 **407**。
- 本实验进一步在 S004 失败区域做更细位置/AGL 预筛：**能同时满足「回传 + 看见 S004 最低点」的位置，与 R01/R02 现有覆盖配对后，仍无法覆盖全部需求**（最佳仍 >0）。
- **E1 结论**：两架各一次固定悬停，在搜索范围内**无法达到 0 中断**。

### E2 —— 两架中继动态换位（多架次）
关键证据：在 T011 的 S004 盲区窗口 [4175, 4582] 内，**除 T011 外仍有 1314 个直接失联样本**（T014=111、T017=407、T021=124、T023=267、T025=405），空间对角跨度 **9439 m**。

| 中继 | 单独覆盖非 T011 样本 | 说明 |
|---|---|---|
| R01 | 1190/1314 = 90.6% | 覆盖北/中部 |
| R02 | 545/1314 = 41.5% | 覆盖南部 |
| 并集 | 1314/1314 = 100% | 需两架 |

**E2 结论**：T011 盲区窗口内，"其余需求"本身就需要**两架中继（北 + 南）**，再加 S004 需要第三架 → **同一时刻需要 3 个视锥，两架中继无论怎样动态换位都无法同时覆盖**（除非存在单个位置能同时覆盖北+南，而北南相距 ~6.9 km 且地形遮挡，单架接入范围 ~6.3 km，不成立）。

### E3 —— 运输架次错峰 + 两架联合
- 滑窗分析（407 s）：全程存在"安静窗口"，非 T011 需求空间跨度最小仅 **48 m**（t≈1705 s），24% 窗口跨度 < 6000 m —— **错峰在原理上可能**。
- 但 **T011 被时间锁死**：T011 使用 U07（C 型），U07 被 T001[0,1496] → T005[1496,2990] → T011[2993,5294] → T015[5294,6974] 背靠背占满，T011 前后零松弛；BAT-C-01 同样被 T001 → T011 占用。
- **E3 结论**：仅平移 T011（及受影响架次）的 start_time 无法把 S004 盲区窗口挪到安静时段，因为 T011 夹在 T005 与 T015 之间零松弛。要释放 T011，需**重排 U07 整条链的架次顺序**，这已超出"错峰 start_time"、进入运输调度重优化范畴（会改变 Q2 组批/路线，与本实验"保持 Q2 固定"的前提冲突）。

## 最终结论

**结论 B**：

> 在本文搜索范围内（固定 Q2 运输方案 + 每架中继一次固定悬停 + 更细静态搜索 + 动态换位可行性 + 错峰可行性），**未找到两架中继的严格可行方案**。最优已找到方案为 **407 个中断样本、覆盖率 98.880361%**。该结果**不构成两架中继全局不可行性证明**。

根因是 **S004 低空谷地的"第三视锥"盲区**：两架中继的空间覆盖最多只够"北 + 南"两个视锥，而 S004 需要"西"向第三个视锥；且 T011 在 U07 上时间锁死，无法靠错峰回避。
