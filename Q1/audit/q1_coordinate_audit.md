# Q1 坐标口径对照审计

**目标**：检验把 Q1 由「WGS84 局部线性米制近似」改用 Q2 已验证的统一 UTM 49N（EPSG:32649）几何口径后，Q1 数值结果是否发生实质变化。

**结论：CASE A —— 坐标口径存在数值差异，但未影响 Q1 离散决策结果。**

## 1. 几何层差异

| 指标 | O01→Si（Q1 实际使用） | 全部 240 航段 |
|---|---|---|
| 水平距离最大绝对差 | 0.692 m（S012） | 3.229 m（S003→S012） |
| 水平距离最大相对差 | 0.0094 % | 0.027 % |
| DEM 最高高程最大差 | **0 m** | **0 m** |
| 巡航海拔/爬升/下降 | **完全相同** | **完全相同** |

距离差异来自投影尺度（局部仿射 ≈ 1.0 尺度 vs UTM 在本地约 1.0001 尺度及微小形变）；DEM 沿线最高高程完全一致，说明 Q1 的 GeoTIFF `RasterPixelIsPoint`（+0.5 像元）与 Q2 的 `.mat` 变换（角点）两者像元解释等价，且「经纬度直线」与「UTM 直线」在本地 DEM 栅格内穿越的像元集合相同。

## 3. 除坐标外的公共物理口径差异

逐项核对 Q1 与 Q2，**未发现坐标之外的实质差异**：

| 口径 | Q1 | Q2 | 一致 |
|---|---|---|---|
| DEM 像元解释 | GeoTIFF IsPoint（+0.5） | .mat 变换角点 | ✅ 等价 |
| 巡航海拔 = 路径最高 DEM + 50 m | ✅ | ✅ | 是 |
| O01 作业高度 = 地面海拔 | ✅ | ✅ | 是 |
| 服务区作业高度 = 地面 + 30 m | ✅ | ✅ | 是 |
| 爬升/下降 = 巡航海拔 − 端点作业高度 | ✅ | ✅ | 是 |
| 水平能耗 E_use·d/L(q)，L(q)=L0−(L0−LF)(q/Q)^1.5 | ✅ | ✅ | 是 |
| 爬升能耗 (M+q)·g·h/(η·3.6e6) | ✅ | ✅ | 是 |
| 下降附加能耗 = 0 | ✅ | ✅ | 是 |
| 返航安全余量（默认 20%） | ✅ | ✅ | 是 |
| 单位（m/s/kg/m³/kWh） | ✅ | ✅ | 是 |

唯一差异即水平投影坐标：Q1 局部仿射 vs Q2 UTM49N。

## 4. 建议

**仅统一论文/代码口径即可**：将 Q1 论文中的「WGS84 局部线性近似」措辞与 Q2/Q3 的「UTM 49N（EPSG:32649）」对齐，并说明经对照实验两者对 Q1 离散结果无影响（CASE A）。Q1 数值结果（架次、组批、机型、敏感性结论）无需正式重算更新；若论文要求各问题数值严格一致，可直接采用 UNIFIED_UTM 的能耗/时间数值（`unified_results/`），其相对差异仅约 0.0025%。
