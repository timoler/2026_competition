## 1. 题目目标

在每架次仅执行 `O01 → 单一服务区 → O01` 的条件下：

1. 计算 A、B、C 三种机型前往15个服务区的最大安全载荷；
2. 在货箱不可拆、每箱只安排一次、质量/体积/返航电量约束下完成组批；
3. 按“累计作业时间、架次数、总能耗”的优先顺序优化；
4. 分析10%、15%、20%、25%、30%返航安全余量的影响。

第一问不考虑实体无人机数量、共享电池调度、充电等待和物资送达时限。

## 2. 模型与方法

- 地形：航段为两节点水平直线，巡航海拔取沿线DEM最高像元高程加50 m；O01作业高度为地面，服务区为地面加30 m。
- 载荷航程：使用题目给出的3/2次幂等效航程关系。
- 能耗补充模型：水平能耗按实际距离占当前等效航程的比例折算电池能量；爬升能耗按 `(空载质量+货物质量)×g×爬升高度/效率` 计算并换算为kWh；下降附加能耗按附件参数取0。
- 安全载荷：满载可行则取额定载荷，空载不可行则标记不可达，其余用65次二分求能源边界。
- 组批：按同质量、同体积的货箱类型建立剩余数量状态，枚举单架次可行模式，通过记忆化动态规划做字典序优化：`累计作业时间 → 架次数 → 总能耗`。
- 时间：单架次累计固定准备、逐箱装载、去程飞行、基础交接、逐箱交接和返程飞行；各架次相加得到累计作业时间。

完整公式、单位和标准算例见[方法与口径](方法与口径.md)。

## 3. 数据处理

- 原始来源：协调人应将官方 `D题` 文件夹原样放置于 `data/raw/D题/`；程序也允许通过第一个命令行参数指定其他只读路径。
- 输入：节点与服务区、物资需求与逐箱清单、运输无人机参数、30米DEM GeoTIFF。
- 规模：1个中心、15个服务区、3种机型、80个货箱；货箱总质量758 kg、总体积2.011 m³。
- DEM：WGS84（EPSG:4326），按像元中心解释；直线穿越像元采用边界切分并保守计入接触像元。
- 数据校验：`results/q1_source_hashes.json` 记录本次运行所用原始文件SHA-256，但不上传原件副本。

主要输出：

- [最大安全载荷及敏感性](results/q1_max_payload_sensitivity.csv)
- [默认20%组批明细](results/q1_batches_default.csv)
- [官方提交字段](results/q1_submission_rows.csv)
- [目标顺序与安全余量对比](results/q1_model_comparison.csv)
- [独立算术复核记录](results/q1_verification.json)
